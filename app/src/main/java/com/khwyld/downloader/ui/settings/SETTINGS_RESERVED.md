# محجوز

شاشة الإعدادات ليست ضمن الشاشات الرئيسية الثلاث لنسخة MVP (active / browser / library).
عند إضافتها لاحقًا، يُقترح تخزين الحقول التالية عبر DataStore (وليس Room لأنها إعدادات وليست بيانات علائقية):

- آخر مجلد حفظ
- الوضع الليلي
- اللغة
- التحميل عبر Wi-Fi فقط (يُستهلك من DownloadScheduler عند إضافته)
- الحد الأقصى للتنزيلات المتزامنة
- تفعيل/تعطيل الأوامر الصوتية

هذا المجلد أُبقي فارغًا الآن حتى لا تُضاف شاشة بلا وظيفة فعلية في النسخة الأولى.
