# Downloader App — نسخة MVP

تطبيق Android مبني باستخدام Kotlin وJetpack Compose لإدارة التنزيلات والتصفح. يستخدم المشروع طبقات `domain` و`data` و`ui`، مع مستودع مستقل لاستخراج روابط الفيديو.

## فتح المشروع

1. افتح المشروع في Android Studio (Giraffe أو أحدث).
2. نفّذ Gradle Sync لتنزيل التبعيات.
3. شغّله على جهاز أو محاكي Android 8.0 (API 26) فأعلى باستخدام JDK 17.

## حالة دعم الفيديو الحالية

- يستخدم `VideoResolverRepositoryImpl` مكتبة NewPipe Extractor لاستخراج روابط فيديو YouTube.
- يدعم التعرف على روابط YouTube من الأنواع watch وyoutu.be وShorts وlive وembed و/v/.
- تظهر للمستخدم الجودات المتاحة التي تحتوي على الصوت والصورة في ملف واحد (progressive streams)، ثم يمرر رابط البث المختار إلى محرك تنزيل Android `DownloadManager`.
- الروابط غير المدعومة كمقاطع فيديو تُعامل كرابط ملف مباشر؛ هذا لا يعني أن كل صفحات المواقع الأخرى قابلة للتنزيل.
- استخراج الروابط يعتمد على تغييرات المنصة، ولذلك لا يمكن ضمان عمل كل فيديو أو كل حساب/منطقة دون اختبار فعلي. الفيديوهات الخاصة أو المقيدة أو التي تتطلب تسجيل الدخول قد لا تعمل.

## حدود معروفة وخطة التوسّع

1. **لا يوجد دمج لمسارات منفصلة بعد.** الجودات التي توفر الفيديو والصوت في مسارين منفصلين لا تُعرض كتنزيل مكتمل. الخطوة التالية هي إضافة واجهة مستقلة مثل `MediaMuxer`/طبقة دمج، واختيار تنفيذ متوافق مع صيغ المصدر، ثم حفظ الناتج النهائي فقط بعد نجاح الدمج.
2. **دعم المنصات قابل للتوسعة.** يجب إضافة محوّل/Adapter مستقل لكل منصة مدعومة، مع اكتشاف المنصة والتحقق من نوع الرابط بدل تمرير كل صفحة ويب إلى محرك التنزيل كما لو كانت ملفًا.
3. **محرك التنزيل الحالي هو `SystemDownloadEngine`.** يعتمد على DownloadManager؛ الإيقاف المؤقت الذي يتحكم به المستخدم ومحرك بديل للتنزيل غير مفعّلين حاليًا.
4. **المكتبة المحلية مبسطة.** تُعرض حالة التنزيل وبيانات الملف الأساسية، دون صور مصغرة حقيقية.
5. **التخزين:** يستخدم DownloadManager مجلد التنزيلات العام؛ يجب التحقق من السلوك على جهاز فعلي وإصدارات Android المستهدفة.

## التحقق قبل الإصدار

يُشغّل GitHub Actions مهمة `gradle assembleDebug` على فروع التطوير وطلبات الدمج. نجاح البناء وحده لا يثبت نجاح تنزيل الفيديو؛ يلزم أيضًا اختبار رابط YouTube عام على جهاز Android، والتحقق من اكتمال الملف وإمكانية تشغيل الصوت والصورة، ثم اختبار فشل رابط غير صالح وإظهار رسالة مفيدة.

عند فشل تنزيل، راجع حالة DownloadManager وقيمة `COLUMN_REASON`، ورسالة الخطأ التي يعرضها المستخرج.
